## 💡 Projects I'm Proud Of

### 🥬 P.I.R.E — Perishable Inventory Risk Engine

An intelligent **MERN-based inventory management platform** designed for small retail stores.

The system uses **XGBoost** to predict expiry risk and classifies products into Low, Medium, and High Risk.

It also provides:

* 📦 Inventory management
* ⚠️ Expiry-risk prediction
* 🔔 Automated expiry notifications
* 💰 Risk-based discount recommendations
* 🌐 Multilingual input & output using NMT
* 🔐 JWT/Bcrypt authentication
* 🗄️ MongoDB Atlas

### 🎬 AI-Powered Ticketing Platform

A full-stack movie ticket booking application combining functionality with a user-focused experience.

**Features include:**

* 🎟️ Real-time seat selection
* 💳 Razorpay payment integration
* 🤖 AI-powered movie recommendations
* 🔐 Firebase + JWT authentication
* ⚡ REST APIs using Node.js & Express

### 🏧 ATM Interface
